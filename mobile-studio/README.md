# SAJI Mobile Video Effects Studio

A phone-friendly browser interface for the original Claude Video Effects project.

## Run in GitHub Codespaces
1. Open this repository on GitHub and switch to branch `mobile-video-effects-studio`.
2. Tap **Code → Codespaces → Create codespace on mobile-video-effects-studio**.
3. Wait for setup to finish. In the terminal run: `python app.py`
4. Open the forwarded port **7860** in the browser. Keep the Codespace running while rendering.

The app downloads the original MIT-licensed effects project from Vibha Ramprakash at startup. It does not bundle or claim ownership of that project.

## Notes
- Cloud rendering, not on-device rendering. Your phone is only the controller.
- Keep the Codespace open while processing. Free account quotas and session limits apply.
- Start with short clips (15–30 seconds) and 720p output to reduce memory and compute use.
- This is a starter mobile interface, not a full timeline editor. Review exports before posting.
